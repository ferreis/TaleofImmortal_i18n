# Tales of Mortal i18N

Mod de tradução comunitária para **Tale of Immortal** e mods associados, com pacotes JSON por idioma.

O desenvolvimento está na branch [`Dev`](../../tree/Dev). A integração no jogo é feita via código C# e patches Harmony, sem XUnity.AutoTranslator.

> Projeto em desenvolvimento. Não há DLL de produção ou tradução completa publicada ainda.
